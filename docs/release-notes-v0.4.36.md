# v0.4.36｜补全空白面板恢复与 Vue 重建修复

## 修复内容

- 修复异步 DOM 挂载期间，布局修复不断重新安装面板、重置超时并绕过重试上限的问题。等待期间不重装；持续失败最多自动重建一次，随后恢复原生输入和重试入口。
- 修复 Nodes 2.0 / Vue 中同一轮注销并注册同名控件可能导致新面板仍未挂载的问题：先卸载旧控件，下一动画帧再重建；等待期间保留重试计数，成功后重置。
- 已移除或折叠的节点不再由布局恢复回调重新安装；已移除节点的待执行安装帧会取消。
- 将“Bridge 面板加载失败（点此重试）”放到原生参数列表顶部，避免埋在大量参数之后；降级和重试保留当前提示词值。

不修改节点接口、模型连线、Python 执行逻辑或提示词/收藏存储格式。

## 更新方式

1. 通过 ComfyUI-Manager 更新，或在插件目录执行 `git pull`；确认版本为 **0.4.36**。
2. 重启 ComfyUI，再按 **Ctrl+F5** 强制刷新浏览器。
3. 若宿主仍不能挂载面板，应看到原生输入和顶部重试按钮，而不是只剩空框；请保留工作流与配置，不必删除模型。

## 验证与边界

- 35 项 Python 单元测试；面板生命周期、拖拽预算、输入事务、控件批处理 4 个 JavaScript 专项；JavaScript 语法与差异格式检查。
- 隔离的 ComfyUI 0.20.1 / 前端包 1.43.18：旧画布及 Nodes 2.0 各测试正常、250 ms 延迟、持续阻断、首次阻断后自动恢复，共 8 个真实浏览器场景，并验证解除故障后的手动重试和提示词保留。
