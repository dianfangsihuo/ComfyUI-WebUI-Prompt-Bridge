# Issue #14：空白面板恢复逻辑补充修复（v0.4.36）

日期：2026-11-05（Asia/Shanghai）。关联 [Issue #14](https://github.com/dianfangsihuo/ComfyUI-WebUI-Prompt-Bridge/issues/14)。

## 判断边界

反馈者使用 bb7ad34 / v0.4.35，报告 Windows 11、Edge、ComfyUI 0.44.0，截图只有节点外框和端口。反馈中尚无控制台异常、独立前端版本及最小工作流，不能认定其具体环境的唯一根因。

本机使用隔离的 ComfyUI 0.20.1、前端包 1.43.18，分别验证 LiteGraph 与 Nodes 2.0 / Vue。普通主面板均能显示；以下故障使用受控 DOM 挂载延迟/阻断复现，不冒充在反馈者机器上的复现。

## 已确认的问题与修复

1. **布局修复绕过挂载宽限和重试上限。** `repairBridgePanelLayoutAfterWorkflow` 的即时/延迟回调在面板尚未连接时直接重新安装；每次安装又安排一组布局修复回调并重置挂载开始时间。旧测试将该函数替换为空函数，因此未覆盖这个反馈环。补充的真实调用链测试中，仅处理 200 个回调便发生了 201 次安装，即使宿主原本只需 250 ms 也无法安稳挂载。
   - 布局修复改用与画布健康检查相同的挂载状态判断；等待期间不重装，最多自动重建一次，持续失败则恢复原生输入。
   - 已移除或折叠节点的布局修复回调不再进行挂载恢复。
2. **Vue 同轮注销/注册同名控件可留下未挂载的新面板。** 浏览器集成测试中，第一次挂载受阻、第二次宿主正常时，立即替换仍可在 Vue 下持续脱离页面；孤立状态机测试无法发现该问题。
   - 重建前先注销旧 DOM 控件，下一动画帧再安装，让宿主处理卸载。等待重建期间保留重试计数，不把它误判为一个全新的恢复周期。
3. **恢复入口可见性。** 原生降级后有大量参数，重试按钮放在末尾不易找到。现将不序列化的重试按钮移至原生控件列表顶部；提示词当前值保持不变。

未修改 Python 执行逻辑、节点接口、模型连线或存储格式；v0.4.36 收录本次修复。
