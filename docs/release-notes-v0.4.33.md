# v0.4.33｜联网翻译诊断与恢复

- **翻译失败可定位**：联网翻译接口现在返回服务错误、网络/SSL 错误、翻译脚本缺失、安装失败和 Python 模块冲突等诊断信息。
- **按钮有反馈**：提示词 Tag 下方的“英”按钮、整段翻译和自动翻译会显示进行中、完成、原文保留或具体失败原因。
- **恢复重试**：联网翻译和中文解释的临时失败不再缓存为空，网络恢复后可以重新请求。
- **修复安装路径**：自动安装翻译资源后直接使用实际安装路径，避免旧 WebUI 路径残留导致翻译模块找不到。

更新后请重启 ComfyUI，并按 `Ctrl+F5` 刷新前端。
