# ComfyUI WebUI Prompt Bridge v0.4.30

这次是一次以交互性能为主的小版本更新。重点减少提示词输入、节点缩放、侧栏拖动和端口标签跟随期间的重复工作，让大型工作流里的 Bridge 控件更跟手，同时保持已有 Prompt、布局和工作流格式兼容。

## 给用户的更新内容

- **提示词输入更流畅**：未变化的隐藏控件不会重复写回；连续输入时会合并 Prompt 卡片刷新和工作流状态通知，文本与隐藏 widget 仍即时同步。
- **节点缩放更跟手**：拖动节点右下角或宽度手柄时不再每个指针事件都提交整份工作流，松开后统一保存最终尺寸和布局。
- **分隔条和侧栏拖动更轻**：拖动期间避免反复写入本地布局存储，结束时一次提交最终值。
- **端口标签后台开销更低**：静止画布跳过重复的 DOM 查询、图节点扫描和位置写入；平移、缩放、节点移动与孤儿覆盖层清理继续保留。
- **提示词小节点同步优化**：正向、反向小节点连续输入时也会合并卡片重建和工作流通知。
- **指针操作更稳**：指针捕获与取消发生竞态时会继续完成拖动清理。

## 本地测量

在 Chromium、完整示例工作流和 120 个 Prompt Tag 场景中：

- 连续提示词输入事件处理中位值从约 `75–90 ms` 降至约 `0.3 ms`。
- 节点缩放事件处理中位值从约 `5 ms` 降至约 `1.8 ms`。
- 60 步侧栏拖动的布局存储写入从 `118` 次降至 `2` 次。
- 端口标签循环自身的 5 秒累计脚本耗时下降约 `70%`。

测量数字用于说明本次优化方向；实际体验仍会受到工作流规模、其他自定义节点和 ComfyUI 节点渲染模式影响。
