# v0.4.37｜修复底部留白与 Nodes 2.0 布局

## 修复内容

- **底部大面积留白**：旧布局可能把 Prompt / LoRA 锁在 220 / 96px，而节点外框仍高达 1705px。现在会修复明显未分配的空间，恢复可用提示词区，并让 LoRA 区使用剩余空间；保留节点宽高和正常手动分区。
- **原生拖动与缩放**：兼容宿主使用 Float32Array 传入节点尺寸；LoRA 高度比较统一使用未缩放的布局像素，避免缩放改变分区。
- **多节点独立布局**：现有面板保留各自的分区高度和侧栏宽度，不再因其他节点更新全局偏好而串用保存状态。
- **快速添加 LoRA 浮层**：关闭后恢复原分区高度和折叠状态，不再丢失原布局。
- **Nodes 2.0 正向/负向小节点**：修复控件与宿主反复叠加接口行高度、导致节点不断长高的循环；词库展开、收起、尺寸调整和重载恢复稳定。

不修改 Python 执行逻辑、模型连线、提示词内容或收藏数据；无需重建工作流、清空配置或删除模型。

## 更新方式

1. 通过 ComfyUI-Manager 更新，或在插件目录执行 `git pull`，确认版本为 **0.4.37**。
2. 重启 ComfyUI，再按 **Ctrl+F5** 强制刷新浏览器，避免继续运行旧的前端脚本。
3. 再打开原工作流检查布局。请先保留工作流备份，不要为解决留白而删除本地配置。

## 验证与边界

- 经典 LiteGraph 与 Nodes 2.0：**28/28 布局场景**通过，另有 **4/4 最终复测**。
- 覆盖尺寸往返、真实手柄拖动、刷新/工作流重载、画布移出/移回、缩放、分区拖动、LoRA 折叠和浮层、侧栏与页签、多节点独立保存、预设/重置，以及正反小节点展开/收起词库。
- **150 组尺寸组合**，**5 组 JavaScript 专项**，**35 项 Python 测试**及语法/差异检查通过。
- 验证宿主为 ComfyUI 0.20.1 / 前端 1.43.18。浏览器矩阵使用中性数据夹具；另在本机完整插件环境复核原留白工作流，未排队出图。
