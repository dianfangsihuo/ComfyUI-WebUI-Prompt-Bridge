# v0.4.35｜空白面板恢复与提示词拖拽优化

## 主要更新

- **空白面板可恢复**：主节点创建自定义 DOM 面板失败时，恢复原生输入框并显示“Bridge 面板加载失败（点此重试）”，不再只剩空白外框；原有提示词值保留。
- **修复面板健康检查**：已经脱离页面的 DOM 不再被当作正常面板。异步挂载有宽限期，自动重建次数有限；旧 DOM 控件在移除时解除宿主登记，避免无效复用和无限重试。
- **减轻拖动开销**：复用 Tag 几何快照和插入指示线；滚动、缩放、卡片重建及异步翻译改变布局后重新测量。落点使用最终指针坐标。
- **减少重复刷新**：主节点拖放及 Alt+方向键排序在更新选区后只提交一次，保留普通输入和翻译重试行为。

节点接口、模型接线和提示词/收藏数据格式不变；延续 v0.4.34 的“关闭图生图时跳过残留图片字段校验”修复。

## 更新后怎么用

1. 更新到 v0.4.35。
2. 启动/重启 ComfyUI，再按 **Ctrl+F5** 强制刷新浏览器。
3. 若自定义面板仍挂载失败，可在原生输入框继续编辑，或点面板失败提示按钮重试；不必删除工作流或重新下载模型。

## 验证范围与边界

- 35 项本地 Python 单元测试通过；面板恢复、拖拽预算、输入事务及控件批处理四个 JavaScript 专项通过，并加入 CI；JavaScript 语法和差异格式检查通过。
- 独立浏览器夹具中，120 个 Tag / 240 次拖动事件：卡片位置读取由 28,800 次降到 120 次；指示线创建由 240 次降到 1 次；事件处理累计耗时从 83.1 ms 降到 4.7 ms。这只代表被测拖拽函数，不代表整个 ComfyUI 页面提速相同比例。
- 本次遵循用户要求只做离线排查，未启动 ComfyUI、未跑完整前端工作流，也未在粉丝机器上验证。修复针对已复现的故障路径，不保证覆盖所有前端版本、浏览器、主题或第三方扩展冲突。
