# v0.4.32｜WebUI 接入兼容与控件响应优化

- **接入 WebUI 更省心**：改善部分本机地址写法触发来源校验的问题；自动检测和手动接入遇到地址问题时，会显示中文原因及处理建议。
- **调整参数减少重复处理**：优化区域控制和高级模块的多参数同步，减少一次操作中的重复工作流记录，参数仍即时生效。
- **沿用现有工作流**：保留节点接口、模型接线和已保存参数，无需重建工作流。

## 更新后怎么用

重启 ComfyUI，再按 **Ctrl+F5** 刷新页面。

若接入仍提示来源不一致，请统一使用 ComfyUI 的同一地址和端口。本机默认可用 http://127.0.0.1:8188（自定义端口请替换）。远程部署请使用服务器的实际地址；自定义域名需设置 `WEBUI_PROMPT_BRIDGE_ALLOWED_HOSTS` 并保留代理的原始 Host。此更新不关闭来源校验，ComfyUI 自身的校验仍然生效。

## 验证范围

通过 Python 单元测试、控件批量更新专项测试和 JavaScript 语法检查。控件专项测试覆盖即时赋值、回调、重复值、异常退出和独立更新。本次优化针对多参数同步，不代表所有机器或全部操作的卡顿都已消除。
