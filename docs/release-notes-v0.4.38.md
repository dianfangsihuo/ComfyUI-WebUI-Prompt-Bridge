# v0.4.38｜Nodes 2.0 空白修复、收藏英译中与标签交互改进

## 主要更新

### 开启 Nodes 2.0 也能显示主面板

维护端在官方前端 **1.58.7** 真实复现了“只有外框、内部全空白”：内部面板已经挂载，但新版 Vue 增加的子网格祖先高度为 0，裁掉了全部内容。这次同步完整控件宿主链，并检查祖先裁切，而不是简单要求关闭 Nodes 2.0。经典节点和原前端 **1.43.18** 继续验证兼容。

不需要删除工作流、配置或模型。用户准确环境及第三方插件组合仍可能不同，原问题保留等待确认。

### 收藏“译中”：先预览，再保存

主节点及正反提示词小节点的提示词/收藏工具区新增 **译中**：

- 搜索、选择单条或多条缺少说明的收藏，每批最多20条。
- 逐条翻译预览，确认后才保存中文名称；不改生成用英文提示词、分类或已有自定义名称。
- 保存前再次核对原文本/名称；期间被修改或删除的条目跳过。
- 显示进度、失败和停止状态，不自动重试；单条最多4000字符/32标签。
- 本地词库优先，联网/AI沿用用户配置，可能产生费用。停止不保证后端或供应商停止处理/计费。

## 更新方法

1. 用 ComfyUI-Manager 更新，或在插件目录执行 `git pull`，确认版本 **0.4.38**。
2. **重启 ComfyUI**（本次有后端接口），再 **Ctrl+F5** 强制刷新浏览器。
3. 开启 Nodes 2.0，重新打开原工作流检查。若仍异常，提供独立前端版本和首条相关 Console 错误；先备份，不删配置。
