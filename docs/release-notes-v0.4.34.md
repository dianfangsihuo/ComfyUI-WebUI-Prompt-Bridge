# v0.4.34｜修复关闭图生图仍触发图片格式校验

## 修复内容

主桥接节点之前在读取“启用图生图输入”开关前，无条件校验图片与遮罩字段。旧工作流即使关闭图生图，只要隐藏字段残留 `img2img` 等非文件名值，也会在正常文生图前报错。

现在关闭图生图时，跳过这些字段的校验和文件读取，输出空图片引用及原有占位 IMAGE/MASK。开启图生图时继续执行格式和路径安全校验；PNG/JPEG/WebP、alpha 遮罩及显式局部重绘遮罩的行为不变。

不修改用户已保存的工作流、提示词、模型接线或其他模块设置。此修复不尝试猜测或重置其他历史异常参数。

## 更新后怎么用

1. 更新节点并重启 ComfyUI（后端 Python 修复只刷新网页不会生效）。
2. 浏览器按 **Ctrl+F5** 刷新。
3. 保持“启用图生图输入”关闭，直接使用原工作流，无需上传图片或重新添加桥接节点。

- 35 项本地 Python 单元测试通过；控件批量更新专项、JavaScript 语法与 Git 差异格式检查通过。
